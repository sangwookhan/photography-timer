# PTIMER-243 iOS predecessor fixture

These four JSON values were captured from the iOS production UserDefaults stores
while running predecessor 1.1.2 from commit
`701154806646e4d357885166360fd6a3c2a30b05` on iPhone 17. They represent the
custom film library, managed camera list, timer state, and timer metadata
snapshots. The capture was produced through the predecessor's production model
and store path; the JSON has not been regenerated with the current encoders.

The films and camera names, identifiers, formulas, table anchors, camera
selections, timer identifiers, timestamps, and timer identities are test data.
No user account, device path, or signing identity is included. The three legacy
Custom films intentionally omit `polarity` and `color`.
