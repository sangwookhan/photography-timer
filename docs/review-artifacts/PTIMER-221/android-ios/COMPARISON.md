# PTIMER-221 iOS / Android comparison matrix

iOS `main@64565f73` on iPhone 17 (`9144ED16`), light, ko-KR.
Android `feature/PTIMER-221-android@79b339c9` on `emulator-5554`
(Pixel_10, API 37), dark (hard-coded), ko-KR.
Provenance and method: see [README.md](README.md).

Classification is one of **Android defect** (correctable, contract- or
evidence-verifiable), **equivalent platform presentation** (a difference
Material or the platform requires, with no capability lost),
**iOS defect** (Android follows the contract, the reference does not), or
**unresolved** (needs a disposition before it can be classified).

**Seed parity.** A row marked `SAME SEED` was captured from the same
seeded state and the same interaction phase on both platforms, and may be
read as visual/transition parity evidence. A row marked `DIFFERENT SEED`
compares the *behavior* only; its images must not be read as visual
parity. Rows being reseeded are marked `RESEED PENDING`.
